# Film Centre Booking and Management System

An academic software development project built using Java and Spring Boot as part of my BSc (Honours) in Computing at Dublin Business School.

## Project Overview

This project explores the development of a booking and management platform for film centres, with a focus on organising studio information and building the backend foundation for a larger reservation system.

## Technologies Used

- Java
- Spring Boot
- Spring Data JPA
- Maven
- IntelliJ IDEA

## Project Structure

- `src/` — Application source code
- `pom.xml` — Maven project configuration and dependencies
- `mvnw` and `mvnw.cmd` — Maven wrapper scripts

## Development Goals

- Model film studio information using Java entities
- Develop the foundation for a booking and management application
- Explore database integration with Spring Data JPA
- Extend the system towards venue, room, event and reservation management

## Project Status

Academic project under development. The repository contains the current implementation; additional booking and management features are planned.
